# Task packets

One `T-00X.md` per task, generated by `/loop-plan` for the current unit of work.

**These are working files, not durable records.** `/loop-plan` clears this directory and renumbers
from `T-001` each time it runs. Nothing here is a record of what happened — that's `loop/STATE.md`
(append-only) and the project's decision records.

A packet is where a task's facts get established *before* a builder reads them: the verified
dependency internals, the conventions in play, the acceptance criteria that make "done" falsifiable.
A claim that lands here wrong costs a build failure; a claim verified here costs nothing.
